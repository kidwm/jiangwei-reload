開始遊玩

在電腦上啟動遊戲

下載對應系統的 ZIP，解壓縮後，依各平台啟動說明將程式放進原版遊戲資料夾並開啟。

看到黑底的啟動畫面時，點一下畫面，或按 Enter 或空白鍵進入遊戲。

從另一台裝置連線

在遊戲主機的「JW_RELOAD」選單開啟「區網伺服器」，並讓另一台裝置連上同一個區域網路。

用 Chrome 安裝區網入口

在要用來遊玩的裝置上，用 Chrome 開啟本站（jiangwei-reload.pages.dev），依下列步驟將這一頁安裝成應用程式。

電腦版 Chrome
  1. 點網址列右側的「安裝」圖示。若找不到圖示，點 Chrome 右上角的「更多」⋮，選「投放、儲存及分享」，再選「將頁面安裝為應用程式」。
  2. 在「三國志姜維傳．RELOAD」的確認視窗點「安裝」。日後可從電腦的應用程式清單開啟。
Android 版 Chrome
  1. 點網址列右側的「更多」⋮，選「安裝並建立捷徑」。
  2. 選「安裝」，依畫面提示完成安裝。回到主畫面或應用程式清單，點「姜維傳 RELOAD」圖示。

開啟入口後，輸入遊戲主機顯示的 IP 與埠號。首次點「授權並連線」時，在 Chrome 提示中選擇「允許」，再由主機玩家核准。

用 iPad Safari 掃碼連線

用 iPad 掃描自己主機畫面上的 QR Code，以 Safari 開啟遊戲。

安裝區網遊戲入口

此入口的區域網路存取已被封鎖。請到 Chrome 的「網站設定」，將這個網站的區域網路權限改為「允許」。

將這個入口安裝成網頁應用程式（PWA），即使遊戲主機換了 IP，也能從同一個圖示開啟並輸入新位址。首次連線時，可直接在應用程式內允許區域網路存取。

請使用支援區域網路存取（LNA）的瀏覽器。以下步驟以 Chrome 為例。

  1. 安裝入口。在電腦上，點網址列右側的安裝圖示，或從「更多」→「投放、儲存及分享」選擇「將頁面安裝為應用程式」。在 Android 上，點「更多」→「安裝並建立捷徑」→「安裝」。
  2. 開啟入口。從主畫面或應用程式清單開啟「姜維傳 RELOAD」，輸入遊戲主機顯示的 IP 和埠號。首次使用時，按「授權並連線」，在瀏覽器的區域網路提示中選擇「允許」。

使用 iPad Safari 遊玩時，可直接掃描遊戲主機上的 QR Code。

連線至區網伺服器

請使用支援區域網路存取（LNA）的瀏覽器遊玩。

在主機上開啟「區網伺服器」，並將兩台裝置連上同一個區網。

首次連線需要區域網路權限。輸入遊戲主機的位址並按「授權並連線」，Chrome 會詢問是否允許這個入口連到區網裝置。
